English translation patch for **Super Robot Taisen Z3: Jigoku-hen** on PS3
(**BLJS10256**, Japanese retail).

This update addresses translation and interface issues reported during playtesting.

### Apply

**The easiest way:** Download [Retro Trans](https://github.com/retro-trans/retro-trans-tools)
from its Releases page. Open **Automatic**, refresh the catalog, and select
your original Japanese ISO or the exact English 0.6.23 ISO. Choose a new output
filename and keep your source image. Use Retro Trans 0.3.1 or later.
Earlier supported English versions can use the existing upgrade chain;
there is no need to launch intermediate game images.

**Other ways:** [DeltaPatcher](https://github.com/marco-calautti/DeltaPatcher)
accepts the same `.xdelta` files. Select your source ISO and its matching patch.

**Command line:** Use [xdelta3](https://github.com/jmacd/xdelta):

| Your source image | Patch |
| --- | --- |
| Original Japanese PS3 release, BLJS10256 | `SRW-Z3-PS3-English-0.6.24-from-original.xdelta` |
| English 0.6.23 | `SRW-Z3-PS3-English-0.6.23-to-0.6.24.xdelta` |

```text
xdelta3 -d -s "original-japanese.iso" "SRW-Z3-PS3-English-0.6.24-from-original.xdelta" "SRW-Z3-English-0.6.24.iso"
```

For the upgrade, use the exact 0.6.23 ISO and its matching upgrade patch.
Do not apply either patch to a different version. If verification fails,
check the input against `BUILD-MANIFEST.json`; **do not disable checksums**.

### What changed since 0.6.23

- **Maximum Break artwork:** repairs the sliced and repeated lettering by
  matching the translated artwork to the animation's nine pieces.
- **Battle and status layouts:** corrects unit-name centering, long skill
  names running into the next row, and overlapping Weapon Rank captions.
- **Tactical and Tag Commands:** translates the live menu choices and
  Tactical effect descriptions. The targeting heading now reads **Tactics**
  so it clears the selection instruction; the menu still says **Tactical Cmd**.
- **Remaining labels:** translates the combat-effect banner family, including
  **A.T. Field**, and the **Gold Bar** reward label.
- **Dialogue and terminology:** standardizes **Quarreling Twins**, corrects
  Annalotta's pronouns, and changes Shinn's surrounded line to refer to Suzaku
  alone. Earlier translation and combat-startup fixes are retained.
- **Validation:** 48 focused tests and the full integrated build checks pass.
  Executable permission checks cover 300 branch edges and 1,137 injected
  instructions. All 554 disc files pass both directory-tree reads.

### PS3 and RPCS3 compatibility

The same wrapped executable and translated assets are supplied for both targets.
For RPCS3, close the emulator and back up your installation before replacing
files. Move only `dev_hdd0/game/BLJS10256_DATA` to a backup outside
`dev_hdd0/game` so the game rebuilds its installation cache. Preserve savedata
and all other games' folders. Fresh-boot the new image and load an in-game save
when testing; emulator save states can retain the old executable and resources.

Modified PS3 requires compatible CFW with fake-SELF support. Stock firmware is
not supported; no blanket HEN or firmware compatibility is claimed. The loader
method has a prior physical-PS3 success report, but this release's preserved
disc layout remains a **hardware candidate** awaiting a console boot report.

Earlier builds received in-game playtesting, including the screenshots that
prompted these fixes. This exact build passed automated binary/layout checks;
the new fixes still need gameplay confirmation on RPCS3 and PS3. Please include
the build number and a screenshot when reporting a problem. See the
[validation notes](https://github.com/retro-trans/SRW-Z3/blob/master/docs/validation/0.6.24.md).

### What's included

English story dialogue, battle captions, pilot/mech/weapon text, glossary and
library text, and translated menu, skill, Spirit and mission-condition text.
The build validates 143 stage archives, 5,635 executable text-hook entries and
all 2,119 inventoried mission/message variants with none missing. These checks
do not establish that every possible screen is translated or fully proofread.
Preset team names and lettering in the opening movie remain unchanged.

Downloads contain two PS3 whole-ISO xdelta patches and three verification files.
There is no Vita or Vietnamese game build in this release. Save conversion is
available separately in Retro Trans's **Z3 saves** tab.
