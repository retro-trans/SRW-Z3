# SRW Z3 Jigoku-hen English 0.6.13 — PS3/RPCS3 patch release

This ZIP contains per-file xdelta patches, NOT a game ISO or Vita package.
Use your own clean Japanese PS3 disc dump, title ID BLJS10256.
The main patch targets RPCS3. It is NOT a confirmed physical-PS3 release:
its EBOOT is the RPCS3 ELF variant, not the separate CFW fake-SELF wrapper.
Do not rebuild it into an ISO and assume it works on hardware or stock firmware.

## Install in RPCS3

Requirements: a clean PS3_GAME folder, Python 3, and xdelta3.
The helper verifies original hashes, then checks each decoded result and keeps
original files as .orig backups. Keep a separate backup of your dump too.

1. Close RPCS3. Extract this patch ZIP into a separate working folder.
2. Open a terminal in that folder and preview the patch:

```text
python apply_xdelta.py --dump "D:\Games\SRWZ3\PS3_GAME" --xdelta "C:\Tools\xdelta3.exe" --dry-run
```

3. If the checks pass, repeat without --dry-run. Apply the whole patch set;
   do not mix fonts, scripts or executable files from different versions.
4. If present, move RPCS3's dev_hdd0/game/BLJS10256_DATA install cache to a
   backup location while RPCS3 is closed. The game recreates it at next boot.
   Do NOT remove anything under dev_hdd0/home/*/savedata.
5. Boot the newly patched folder, not an older ISO registered in RPCS3.

This ZIP's from-original patches require clean files, not 0.6.3 files.
The separately generated from-previous set is specifically 0.6.3 -> 0.6.13;
it is not included in this full-install ZIP. Whole-ISO patches are separate
GitHub release assets: use the release's Downloads section for the full ISO
patch or exact-v0.6.3 update, including required source/output hashes.

## Changes since the last packaged release, 0.6.3

- Stage-transition archive metadata repair for the stage-10 ending/skip
  black-screen report; corrected packed-table sizes and validation.
- Approved English title logo/subtitle artwork.
- Menu, library, faction/episode and record-screen translations and alignment.
- Intermission/pilot-change, training/help, parts/preparation popups, controls,
  currency and support-squad labels, and keyword-background sizing fixes.
- Pilot TOP 5 and Trade List title consolidation and overlap fixes.

This packages the already validated 0.6.13 build, without changing its text,
version number or adding Vita-only hooks. All 186 delivered files are verified
against its build manifest; each xdelta is decoded and checked against those
files before packaging. No complete game files are distributed in the ZIP.

Translation is still partial: the build reports 1,034 untranslated mission-text
variants. Full playthrough, combined live layout and physical-console testing
are not claimed complete. Japanese voices are unchanged.

## Physical PS3

A separately prepared 0.6.13-CFW-test1 package uses fresh disc metadata and a
CFW fake-SELF wrapper, plus FAT32-compatible split ISO files. It remains a
hardware-unverified test for existing CFW/Cobra systems, not stock firmware.
Do not substitute this RPCS3 patch's EBOOT for that wrapper. Ask for the CFW
test package specifically if you are testing on a physical console.
