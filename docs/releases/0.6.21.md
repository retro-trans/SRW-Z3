English translation patch for **Super Robot Taisen Z3: Jigoku-hen** on PS3
(**BLJS10256**, Japanese retail).

### Apply

**The easiest way:** Download [Retro Trans](https://github.com/retro-trans/retro-trans-tools)
from its Releases page. Open the **Automatic** tab, refresh the catalog,
select your original Japanese ISO, and let the app identify it before patching.
Choose a new output filename and keep your original image.

**Command line:** Use [xdelta3](https://github.com/jmacd/xdelta) with the full
patch below. Do not use an already-patched English image as the source.

| Your source image | Patch |
| --- | --- |
| Original Japanese PS3 release, BLJS10256 | `SRW-Z3-PS3-English-0.6.21-from-original.xdelta` |

```text
xdelta3 -d -s "original-japanese.iso" "SRW-Z3-PS3-English-0.6.21-from-original.xdelta" "SRW-Z3-English-0.6.21.iso"
```

If the patcher reports a checksum mismatch, check your source against these
values. **Do not disable source verification.**

- Original ISO: **4,431,872,000 bytes**
- Original SHA-256: `1b45cdd1651b98fe24b544223488289790ae87d5f82f1db272285fb4e4dffa89`
- Original MD5: `2cfedd95e5bdde49550cffa21c3c29a3`
- Patched ISO: **5,011,013,632 bytes**
- Patched SHA-256: `b67c0a23924e79ab31d28c9b726535473087eee9bf8e5dd4758ce4c6ec64c3e0`

The full patch is approximately 154.8 MB. Check the complete output against
`BUILD-MANIFEST.json` before use. `SHA256SUMS.txt` contains download checksums;
`VALIDATION.json` records the successful local patch round trip.

If Retro Trans reports that its catalog removed a patch, close the app,
rename `%LOCALAPPDATA%\RetroTrans\cache\catalog.json` to a backup name,
then reopen and refresh. This affects clients that cached the initial catalog
entry; manual full-patch installation is unaffected.

### What changed

- **D-Trader dialogue.** Translates all 102 ace-pilot congratulations scenes,
  including Sousuke's alternate scenes.
- **Activation and learning prompts.** Translates NT-D, Trans-Am, GAI and
  Tengen Toppa confirmations, plus skill-learning, upgrade and overwrite messages.
- **Battle speaker names.** Completes the fallback-speaker table, including
  Zessica, with 1,155 canonical English display slots.
- **Pilot headings and layout.** Corrects duplicated surnames such as Asuka's
  and Mari's, updates Spirit-list layout, and adjusts bonus-description and
  full-upgrade-message alignment.
- **Weapon requirements and songs.** Translates the live requirement warning
  list, Newtype levels, Song EN, song effects and related labels.
- **Battle menus.** Translates special-skill activation banners, battleship
  deployment headings and remaining-unit counters.
- **E-Change and equipment.** Translates command help, the Spirit-effect
  warning and every named swap-equipment option in both equipment tables.
- **Dialogue terminology.** Corrects Rare Igura/Iguras usage, Shotaro's pronoun
  and reviewed Mikage wording.

The patch was applied locally to its specified source and reproduced the
complete target hash. Automated checks cover 5,445 executable text hooks,
2,119 mission-text variants, battle-subtitle readback and pilot-name composition.
All 554 disc files were verified in both ISO directory trees, alongside
35 focused regression tests and the executable-wrapper round trip.
These checks do not guarantee that every screen is error-free.

### PS3 / RPCS3 compatibility

For RPCS3, close the emulator and back up your installation before replacing
game files. With RPCS3 closed, move `dev_hdd0/game/BLJS10256_DATA` to a backup
outside `dev_hdd0/game` so the game rebuilds its installation cache.
Do not remove savedata or other games' folders.

For modified PS3, the executable is a debug/fake SELF requiring compatible
CFW with fake-SELF support. Unmodified retail firmware is not supported;
no blanket HEN or firmware compatibility is claimed. The executable packaging
uses a previously hardware-tested method, but this exact disc layout remains
a **hardware candidate** without confirmed physical-console boot.

In-game playtesting has identified remaining text and layout issues.
Corrections for battle speaker corruption, missing scenario speaker headers,
Fury/Break terminology, Song Soul spacing and D-Trader purchase/unlock messages
exist in the current source but are **not included in this patch**.
Please include the build number and a screenshot when reporting problems.

### What's included

English story dialogue, battle captions, pilot/mech/weapon text, glossary and
library text, and translated menu, skill, Spirit and mission-condition text.
This is not a claim that every possible screen has been translated or proofread.
Preset team names and lettering in the opening movie remain unchanged.

Downloads contain one PS3 full-ISO xdelta and its three verification files.
There is no Vita patch or Vietnamese build in this release. Save conversion
is available separately in Retro Trans's **Z3 saves** tab.

### How it was translated

This project uses AI-assisted translation drafts, followed by terminology
checks, editing and playtesting. Community references guide names and terminology.
Proofreading and corrections are welcome.
