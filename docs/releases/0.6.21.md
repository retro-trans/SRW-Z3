# English patch 0.6.21 — PS3 / RPCS3

For the Japanese retail PS3 version of Super Robot Wars Z3: Jigoku-hen
(BLJS10256). Requires your own game dump. Downloads contain patches, not a game.

## Changes since the published 0.6.19

- Translated all 102 D-Trader ace-pilot congratulations scenes, including
  Sousuke's alternate scenes.
- Translated activation confirmations (NT-D, Trans-Am, GAI and Tengen Toppa)
  and skill-learning, upgrade and overwrite messages.
- Completed the battle fallback-speaker name table, including Zessica:
  1,155 display slots now use canonical English names.
- Fixed duplicated surnames in pilot status headings, including Asuka and
  Mari. Adjusted both Spirit lists so full names such as Fighting Spirit
  clear the SP-cost column.
- Translated the live weapon-requirement warning list and Newtype level
  requirements, plus Song EN, song effects and related song labels.
- Translated special-skill/ability activation banners, battleship deployment
  headings and remaining-unit counters.
- Translated E-Change help and its Spirit-effect warning, adjoining command
  help, and every named swap-equipment option in both equipment tables.
- Corrected Rare Igura/Iguras terminology across dialogue, battle subtitles
  and library text. Fixed the Shotaro pronoun and reviewed Mikage wording.
- Corrected centering for single-line bonus descriptions and the full-upgrade
  lock message.

This includes the fixes from local build 0.6.20, which was not published.
It is not a claim that every possible game screen is translated or proofread.
Preset team names and lettering in the opening movie remain unchanged.

## Installation and runtime status

The complete build passes its production checks: 5,445 executable text hooks,
2,119 mission-text variants with none missing from the audited inventory,
battle-subtitle readback, pilot-name composition, Spirit-column clearance,
and UI/layout regressions. Thirty-five focused tests also pass, including
a new check for glossary initialization in the separate UI builder.
All 554 files are verified in both ISO directory trees; the delivered
executable also passes the RPCS3 debug-SELF extraction round trip.

For RPCS3, close the emulator and back up the previous installation before
replacing it with the verified image's files. With RPCS3 closed, move
`dev_hdd0/game/BLJS10256_DATA` to a backup outside `dev_hdd0/game` so the
game rebuilds its cache. Do not remove savedata or other games' folders.

For modified PS3, the executable is a debug/fake SELF, not a retail signature.
It requires compatible CFW with fake-SELF support; unmodified retail firmware
is not supported. No blanket HEN or firmware compatibility is claimed.

The executable packaging follows the user-tested 0.6.15 method. The
preserved disc layout introduced in 0.6.18 keeps patches small, but has no
hardware boot confirmation yet. Treat this as a **hardware candidate**.
New 0.6.21 gameplay and visual checks remain pending on both targets;
automated validation is not a gameplay test. Please report problems with
the build number and a screenshot.

Vita and save-tool assets are unchanged and remain on the
[v0.6.14 release](https://github.com/retro-trans/SRW-Z3/releases/tag/v0.6.14).
This release is PS3 only. The repository remains private; no public catalog
enrollment is performed. GitHub's automatic source archives reflect the
tagged source commit.
