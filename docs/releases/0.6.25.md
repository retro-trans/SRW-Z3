English translation patch for **Super Robot Taisen Z3: Jigoku-hen** on PS3
(**BLJS10256**, Japanese retail).

This update addresses translation, pilot-name and interface issues reported
during playtesting.

### Apply

Use [Retro Trans](https://github.com/retro-trans/retro-trans-tools), version
0.3.1 or later. Open **Automatic**, refresh the catalog, and select your
original Japanese ISO or the exact English 0.6.24 ISO. Choose a new output
filename and keep your source. Earlier supported English versions can follow
the existing upgrade chain without launching intermediate game images.

[DeltaPatcher](https://github.com/marco-calautti/DeltaPatcher) or
[xdelta3](https://github.com/jmacd/xdelta) can apply the same patches:

| Your source image | Patch |
| --- | --- |
| Original Japanese PS3 release, BLJS10256 | `SRW-Z3-PS3-English-0.6.25-from-original.xdelta` |
| Exact English 0.6.24 | `SRW-Z3-PS3-English-0.6.24-to-0.6.25.xdelta` |

```text
xdelta3 -d -s "original-japanese.iso" "SRW-Z3-PS3-English-0.6.25-from-original.xdelta" "SRW-Z3-English-0.6.25.iso"
```

Do not apply a patch to another version. If verification fails, compare your
input with `BUILD-MANIFEST.json`; **do not disable checksums**.

- Original Japanese ISO: **4,431,872,000 bytes**, SHA-256
  `1b45cdd1651b98fe24b544223488289790ae87d5f82f1db272285fb4e4dffa89`.
- English 0.6.24 ISO: **5,018,877,952 bytes**, SHA-256
  `9ef889abf4a433a06c7627954f1dea9ab36b026abfe515cd18896aa4fcbd0c07`.
- Patched 0.6.25 ISO: **5,018,877,952 bytes**, SHA-256
  `6f24821375687edce6fabe684e2ccd6b14811731023de5a3e4f0ab5342cf1f1b`.

`BUILD-MANIFEST.json` records the complete input/output identities.
`SHA256SUMS.txt` verifies downloads and `VALIDATION.json` records local
full-image patch round trips. Both routes produce the same complete ISO.
Both patches were decoded locally and matched the complete target hash.
Downloads are **155.5 MB** from original or **21.2 MB** from 0.6.24.

### What changed since 0.6.24

- **Combat-effect banners:** measured centering keeps labels such as
  Lambda Driver inside their banner.
- **Ace Bonus notice:** translates the complete acquired-bonus sentence and
  aligns its highlighted words.
- **Pilot names:** removes unwanted middle dots in Pilot Info, adds missing
  surname/given-name spaces, and corrects **Hilde Schbeiker**.
- **Spirit selection:** centers the full **Commander Tanaka** name within
  its card without abbreviating it.
- **Terminology:** replaces organization references to "Echoes" with **ECOAS**.
- **Dialogue:** fixes "Destroying it is," awkward Ryouma line breaks,
  Hibiki's observation about someone else's sarcasm, and the fused wording
  in the Pony Man descriptions. Adds missing spaces around highlighted
  **White Fang** and **PS** links.

Earlier translation and combat-startup fixes are retained.

The full build checks and 41 focused tests passed. All 554 disc files were
verified in both filesystem trees. The broader historical test suite is not
fully green; its old-fixture and replay limitations are detailed in the
validation notes below.

### PS3 and RPCS3 compatibility

Both targets use the same wrapped executable and translated assets. For
RPCS3, close the emulator and back up your installation before replacing
files. Move only `dev_hdd0/game/BLJS10256_DATA` to a backup outside
`dev_hdd0/game` so the game rebuilds its installation cache. Preserve savedata
and all other games. Fresh-boot the new image and load an in-game save;
emulator save states can retain old code and resources.

Modified PS3 requires compatible CFW with fake-SELF support. Stock firmware
is not supported; no blanket HEN or firmware compatibility is claimed. The
loader method has a prior physical-PS3 success report, but the preserved
disc layout remains a **hardware candidate** awaiting a console boot report.

Earlier builds received in-game playtesting, including the screenshots behind
these corrections. These new fixes still need gameplay confirmation on RPCS3
and PS3. Please include the build number and a screenshot with reports. See
the [validation notes](https://github.com/retro-trans/SRW-Z3/blob/master/docs/validation/0.6.25.md).

### What's included

English story dialogue, battle captions, pilot/mech/weapon text, glossary,
library and translated menu, skill, Spirit and mission-condition text.
The build validates 143 stage archives, 5,635 executable text-hook entries
and all 2,119 inventoried mission/message variants with none missing.
Coverage checks do not establish that every possible screen is translated
or fully proofread. Preset team names and opening-movie lettering remain
unchanged. No Vita or Vietnamese game build is included. Save conversion is
available separately in Retro Trans's **Z3 saves** tab.

### How it was translated

This project uses AI-assisted drafts followed by terminology checks, editing
and playtesting. Community references guide names and terminology.
Proofreading and corrections are welcome.
