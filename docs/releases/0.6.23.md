English translation patch for **Super Robot Taisen Z3: Jigoku-hen** on PS3
(**BLJS10256**, Japanese retail).

**Combat-crash correction for 0.6.22.** The new battle-name code in that
version was placed in non-executable memory. This release moves it into
executable memory and adds checks to prevent that packaging mistake.

### Apply

**The easiest way:** Download [Retro Trans](https://github.com/retro-trans/retro-trans-tools)
from its Releases page. Open **Automatic**, refresh the catalog, and select
your original Japanese ISO or the exact English 0.6.22 ISO. Choose a new output
filename and keep your source image. Use Retro Trans 0.3.1 or later.
For 0.6.21, Automatic can chain the existing 0.6.21-to-0.6.22 patch and this
upgrade; there is no need to launch the intermediate game image.

**Command line:** Use [xdelta3](https://github.com/jmacd/xdelta) with the patch
that matches your source:

| Your source image | Patch |
| --- | --- |
| Original Japanese PS3 release, BLJS10256 | `SRW-Z3-PS3-English-0.6.23-from-original.xdelta` |
| English 0.6.22 | `SRW-Z3-PS3-English-0.6.22-to-0.6.23.xdelta` |

```text
xdelta3 -d -s "original-japanese.iso" "SRW-Z3-PS3-English-0.6.23-from-original.xdelta" "SRW-Z3-English-0.6.23.iso"
```

For the upgrade, use the 0.6.22 ISO and its matching upgrade patch instead.
Do not apply either patch to a different version. If verification fails,
check your input against `BUILD-MANIFEST.json`; **do not disable checksums**.

### What changed

- **Combat startup:** corrects the confirmed 0.6.22 execution fault in the
  shared battle-speaker-name handling. All three copy paths and the draw path
  now use existing read-only executable space; no data memory is made executable.
- **Regression protection:** checks patched direct branches and reachable
  injected instructions in the source executable, hardware layout and final
  wrapped executable. The tests reject the faulty released 0.6.22 files.
- **Validation:** 44 focused tests pass; the full build passes its integrated
  checks. The final permission audit covers 283 direct branch edges and
  1,068 injected instructions. All 554 disc files pass both directory-tree reads.
- **Translations retained:** includes all 0.6.22 translation/UI improvements,
  including 24 demo titles, narration and retreat text, D-Trader messages,
  speaker headers and terminology corrections. No new translation batch here.

### PS3 / RPCS3 compatibility

The same wrapped executable and translated assets are supplied for both targets.
For RPCS3, close the emulator and back up your installation before replacing
files. Move only `dev_hdd0/game/BLJS10256_DATA` to a backup outside
`dev_hdd0/game` so the game rebuilds its installation cache. Preserve savedata
and all other games' folders.

Modified PS3 requires compatible CFW with fake-SELF support. Stock firmware is
not supported; no blanket HEN or firmware compatibility is claimed. The loader
method has a prior physical-PS3 success report, but this release's preserved
disc layout remains a **hardware candidate** awaiting a console boot report.

Earlier builds have received in-game playtesting, including the screenshots
that prompted these fixes. This exact build has automated binary/layout checks;
the corrected combat path still needs in-game confirmation on RPCS3 and PS3. Please report
the build number and include a screenshot when reporting a problem.
Detailed checks and limitations are recorded in the
[validation notes](https://github.com/retro-trans/SRW-Z3/blob/v0.6.23/docs/validation/0.6.23.md).

### What's included

English story dialogue, battle captions, pilot/mech/weapon text, glossary and
library text, and translated menu, skill, Spirit and mission-condition text.
The build validates 143 stage archives, 5,623 executable text-hook entries and
all 2,119 inventoried mission/message variants with none missing. These checks
do not establish that every possible screen is translated or fully proofread.
Preset team names and lettering in the opening movie remain unchanged.

Downloads contain two PS3 whole-ISO xdelta patches and three verification files.
There is no Vita or Vietnamese game build in this release. Save conversion is
available separately in Retro Trans's **Z3 saves** tab.
