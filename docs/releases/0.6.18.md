# English patch 0.6.18 — PS3 / RPCS3

For the Japanese retail PS3 version of Super Robot Wars Z3: Jigoku-hen
(BLJS10256). Requires your own game dump. Downloads contain ISO patches,
not a complete game.

## What changed since 0.6.14

0.6.15–0.6.17 were local test builds and were never published; their fixes
are all included here.

- **All 116 story scripts are translated**, and **every mission victory,
  defeat and SR Point condition has English**. 0.6.14 had 1,034 untranslated
  mission-condition variants; this build has none. Eleven small non-story
  scripts remain in Japanese.
- **One disc for RPCS3 and a modified PS3.** The executable is packaged the
  same way as the user-confirmed `0.6.15-hardware-test1` (two-LOAD layout,
  original-metadata fake SELF, corrected disc header). See the hardware notes
  below.
- Workarounds for truncated or corrupted battle names (Fourth Angel, Neo Zeon
  Soldier, Space Demon King Soldier). These have not yet been checked in the
  affected battles. Mariemaia Soldier is still unresolved.
- Unit Data sword-icon help, name-entry screen labels and the Berserk cut-in
  are translated.
- Dialogue fixes, including Episode 25 stray quote marks, Stage 17 and 19
  jokes, and Toji's and Fa's lines. Also Operation Yashima (Rei, Kurz,
  Shotaro, Sosuke) and Tessa's cover-story scene in Stage 32.

apply both patches in sequence.

## RPCS3

Close the emulator, extract the verified image's `PS3_GAME` folder with an ISO
tool (or boot the ISO directly), and back up your previous installation.
With RPCS3 CLOSED, move `dev_hdd0/game/BLJS10256_DATA` to a backup outside
`dev_hdd0/game` so the game rebuilds its data on first boot. Never remove
`dev_hdd0/home/.../savedata` or other games' folders.

## Modified PS3 (CFW with fake-SELF support)

The executable is a debug/fake SELF, **not a retail signature**. It needs CFW
with fake-SELF support (e.g. Cobra) and does not work on unmodified retail
firmware. Load the ISO through your backup manager as usual.

**Hardware status:** the executable packaging matches a build the maintainer
confirmed booting on a modified PS3 (0.6.15). This release uses a new disc
layout: unchanged files keep their original positions, which is what keeps
the patches small. **That layout has not been boot-tested on hardware yet.**
Please report whether it boots. If it does not, booting your untouched
Japanese ISO first will rule out the console setup.
