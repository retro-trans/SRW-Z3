# English patch 0.6.13 — Time Prison

For the Japanese retail PS3 version of Super Robot Wars Z3: Jigoku-hen
(BLJS10256). Requires your own game dump. Downloads contain ISO patches,
not a complete game. Apply them with xdelta3.

## Changes since 0.6.3

- Corrected packed archive metadata associated with the stage-10 ending/skip
  black-screen report.
- Approved English **Super Robot Wars** title logo and **Time Prison Chapter**
  subtitle artwork.
- Translation and alignment fixes for intermission, pilot changes,
  library/faction/episode labels, records, training/help and parts/preparation
  menus.
- Currency, support-squad, control-label and keyword-background fixes.
- **Pilot TOP 5** and **Trade List** titles and overlap fixes.

## Downloads

- `SRW-Z3-English-0.6.13.iso.xdelta` (149.1 MB): apply to the pristine Japanese ISO.
- `SRW-Z3-English-0.6.3-to-0.6.13.iso.xdelta` (14.8 MB): update the exact 0.6.3 ISO.

Original ISO: **4,431,872,000 bytes**, MD5
`2cfedd95e5bdde49550cffa21c3c29a3`.
The update requires the 0.6.3 ISO: **4,996,820,992 bytes**, MD5
`7936d74e28e5b7259ab6666a967e71a7`.
Both patches produce the same **4,996,823,040-byte** 0.6.13 image, MD5
`3259c2c80a98d846dcf775649990a561`.

Apply the full ISO patch to your original Japanese image:

```text
xdelta3 -d -s "Dai-3-Ji Super Robot Taisen Z - Jigoku-hen (Japan).iso" "SRW-Z3-English-0.6.13.iso.xdelta" "SRW-Z3-English-0.6.13.iso"
```

If you already have the exact v0.6.3 image, use the smaller update instead:

```text
xdelta3 -d -s "SRW-Z3-English-0.6.3.iso" "SRW-Z3-English-0.6.3-to-0.6.13.iso.xdelta" "SRW-Z3-English-0.6.13.iso"
```

Choose one patch; you do not need both downloads. Do not apply the full
patch to an already patched image or apply the update to another version.

Close RPCS3 first and move only `dev_hdd0/game/BLJS10256_DATA` to a backup
location before launching the new version. The game recreates this cache.
Preserve your savedata folder and keep a backup of your dump. Make sure RPCS3
boots the new version, not an older copy still registered in the game list.

Use the uploaded patch assets, not GitHub's automatic “Source code” downloads.
The tag points to the published source tip; uncommitted local build-source
changes are not included in those automatic source archives.

## Scope and verification

**This is a partial translation, not a 100% release.** The build reports
**1,034 untranslated mission-text variants**. Full playthrough and combined
live-layout verification remain pending. Japanese voice audio is unchanged.

All 190 build-manifest files were checked before snapshotting the 186 delivered
game files.
All 186 game files were read back from both ISO directory trees and compared
with the release snapshot. Both distribution ISO patches were independently
decoded and compared with the same release image; both outputs match.
The 25 focused ISO-planner, package, build-version and CPK regression tests passed.

**This package targets RPCS3. Physical PS3 compatibility is not established.**
The separate 0.6.13-CFW-test1 package uses a different executable wrapper and
disc layout; it remains a hardware-unverified CFW/Cobra test and is not
included here. These downloads are not suitable for stock PS3 firmware.
The ISO patches retain the previous release's legacy RPCS3 image layout;
they do not address physical-console disc-metadata or executable requirements.

Automated checks are not a full in-game playthrough or proof of hardware
compatibility. No gameplay-condition changes are intended; applying the ISO patch
does not modify saves.
