## Broader test-suite limitations

Do not interpret the focused and integrated passes as an all-repository test
pass. The unrestricted all-platform discovery run terminated in an emulator
test with "Could not allocate dynamic translator buffer." A diagnostic run
excluding Vita-named modules completed 519 tests, initially reporting 19
failure/subtest entries and four import errors. Logs are retained locally in
`work/tests_ps3_0.6.25.log` and `.json`.

The import errors came from that temporary runner omitting the repository
root. Correct-path reruns passed the ace/distribution and link-packager checks;
historical date-card replay and startup-menu checks still reject their older
fixtures. The startup test expects a particular older English UI archive in
the live `game/` directory, not the current installed build.

Other failures compare old .3/.12/.15/.16 outputs or historical incremental
patch endpoints with current text/artwork/hooks: battle action menus/artwork,
deployment labels, Focus deltas/name counts, gift and President wrappers,
map words, date wrappers, search sprites and upgrade/library labels. One
skill-description test assumes the hook loader returns only 124 rows; current
loading additionally includes the shared hooks. These historical tests have
not been disabled or presented as passing. Their current-build UI/code
counterparts pass in the integrated build gate.

The voice token expansion test received narrow maintenance: it now checks
exact glossary output and retains Igura coverage. The old halfwidth-quote
replay also compares current Stage 25 text with frozen .15/.16 dialogue;
later wording and link-space corrections invalidate its quote-only equality.
It remains unchanged and failing, rather than rewriting historical fixtures.
Current link spacing and absence of halfwidth cells pass the new screenshot
and catalog checks.
